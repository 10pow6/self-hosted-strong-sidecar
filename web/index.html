Program JSON

      
Saved to programs/<slug>.json. Sets use pct (% of 1RM or training max) or an absolute weight_lb / weight_kg;
        rounding is rounding_lb / rounding_kg;
        amrap, reps_max, rpe, warmup are optional. lifts maps each lift key to your Strong exercise name.

Claude skill: strong-coach

      
Lets Claude read this API and suggest your next session for an exercise, e.g. "what should my next bench session be?".
        The zip contains SKILL.md (how to read your data and make a recommendation) and references/api.md
        (every endpoint below), already pointed at .

Install

      
    
        
  • Claude Code (recommended): already active in this project (.claude/skills/strong-coach). To use it from any folder:
          
    unzip -o strong-coach.zip -d ~/.claude/skills/
    • 
        
  • Claude apps (claude.ai / desktop): upload the zip as a custom skill in Claude's settings.
          Skills there run in Anthropic's cloud sandbox, which can't reach 127.0.0.1. They only work if this API is
          reachable at a public URL. Download with that address baked in: /api/v1/skill.zip?base_url=https://your-host.
